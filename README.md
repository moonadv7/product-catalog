# كتالوج المنتجات

كتالوج ثابت للمنتجات، يدعم العربية والإنجليزية والبحث بالاسم أو الباركود وتصفية العروض والمنتجات الجديدة وقائمة المنتجات والكميات.

مستودع المصدر: https://github.com/moonadv7/product-catalog

## الملفات والنشر

- `index.html`: الصفحة الرئيسية.
- ملفات JavaScript وCSS وSVG: مصدر واجهة الكتالوج.
- `images-*.zip`: صور المنتجات موزّعة على أرشيفات لتسهيل رفعها إلى GitHub. يحتوي كل أرشيف على مسارات `assets/products/` أو `assets/offers/`.
- `build.mjs`: يفك أرشيفات الصور ويجمع الموقع في مجلد `public`.
- `vercel.json`: إعداد نشر الموقع على Vercel. أمر البناء `npm run build` ومجلد الإخراج `public`.

روابط المنتجات تستخدم `?product=BARCODE` وروابط الأقسام تستخدم `?category=ID`، وتعمل مباشرة دون إعداد خادم.

تُحفظ قائمة المنتجات واللغة في متصفح الزائر. لا توجد نماذج مراسلة أو أرقام تواصل للمورد.

الكتالوج نسخة ثابتة بتاريخ 17 نوفمبر 2026. بيانات المنتجات والعروض لا تتحدث تلقائيًا.
